# # Python Projects – Data Science, Machine Learning & Automation

A collection of Python projects developed to explore practical applications of data analysis, data visualization, machine learning, chatbot development, and task automation.

This repository brings together four independent projects demonstrating the use of Python libraries and concepts to solve different real-world problems.

## Projects Overview

### 1. Automated Report Generation

**Objective:** Automate the process of analyzing structured data and generating professional PDF reports.

**Key Features:**
- Creates and processes datasets using Pandas.
- Generates descriptive statistical summaries.
- Visualizes data using Matplotlib.
- Automatically generates PDF reports with tables and charts.

**Technologies:** Python, Pandas, Matplotlib, ReportLab.

**Source Code:** [automated report generation.py](https://github.com/Fathima2526/PYTHON-PROJECT/blob/main/automated%20report%20generation.py)

### 2. Data Visualization Using Matplotlib & Seaborn

**Objective:** Transform numerical data into meaningful visual representations for easier analysis and interpretation.

**Key Features:**
- Creates different types of data visualizations.
- Uses Matplotlib and Seaborn for graphical representation.
- Presents patterns, distributions, and relationships in datasets.
- Improves understanding of data through visual analysis.

**Technologies:** Python, Matplotlib, Seaborn.

**Source Code:** [visualize_matplotlib_seaborn.py](https://github.com/Fathima2526/PYTHON-PROJECT/blob/main/visualize_matplotlib_seaborn.py)

### 3. Spam Email Classification Using Naive Bayes

**Objective:** Develop a machine learning model that classifies emails as spam or legitimate messages.

**Key Features:**
- Loads and preprocesses email datasets.
- Performs text cleaning and feature extraction using TF-IDF.
- Trains a Multinomial Naive Bayes classifier.
- Evaluates model performance using accuracy, classification reports, and confusion matrices.
- Predicts whether new email messages are spam or legitimate.

**Technologies:** Python, Pandas, Scikit-learn, TF-IDF, Naive Bayes, Matplotlib.

**Source Code:** [email_prediction.py](https://github.com/Fathima2526/PYTHON-PROJECT/blob/main/email_prediction.py)

### 4. NLP-Based Chatbot Using NLTK

**Objective:** Develop a basic conversational chatbot that responds to user inputs using Natural Language Processing concepts.

**Key Features:**
- Identifies user inputs using predefined patterns.
- Uses regular expressions for pattern matching.
- Generates responses based on recognized inputs.
- Includes fallback responses for unrecognized queries.

**Technologies:** Python, NLTK, Regular Expressions.

**Source Code:** [nltk chatbot.py](https://github.com/Fathima2526/PYTHON-PROJECT/blob/main/nltk%20chatbot.py)

## Getting Started

### Prerequisites

- Python 3.x
- pip (Python package manager)

### Installation

Clone the repository:

```bash
git clone https://github.com/Fathima2526/PYTHON-PROJECT.git
```

Navigate to the project directory:

```bash
cd PYTHON-PROJECT
```

Install the required libraries:

```bash
pip install pandas matplotlib seaborn scikit-learn reportlab nltk
```

### Running the Projects

Run the required Python file independently:

```bash
python "automated report generation.py"
```

```bash
python visualize_matplotlib_seaborn.py
```

```bash
python email_prediction.py
```

```bash
python "nltk chatbot.py"
```

**Note:** The spam email classification project requires the `spam.csv` dataset in the project directory.
